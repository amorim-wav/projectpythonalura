# Projeto Python Alura

Projeto final da unidade **Introdução a Python: desafios de programação**.

O programa simula um mercadinho simples com:

- lista de produtos e preços;
- saldo inicial do usuário;
- compra de produtos por quantidade;
- validação de saldo;
- carrinho de compras;
- consulta do saldo restante;
- resumo final das compras.

## Como executar

Use Python 3 e rode:

```bash
python projeto_mercadinho_python.py
```

O projeto utiliza variáveis, operações matemáticas, condicionais, laços de repetição, funções, listas e dicionários.
